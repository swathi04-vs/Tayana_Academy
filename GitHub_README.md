# Core Prompting Techniques Exercises

## Overview
This repository demonstrates three important prompting techniques:
- Chain-of-Thought (CoT)
- ReAct (Reason + Act)
- Self-Consistency

## Learning Objectives
- Improve reasoning quality
- Create structured responses
- Evaluate and refine outputs
- Build reliable AI-assisted workflows

## Exercises
### Chain-of-Thought
1. Divisibility by 9
2. Marketing Message Evaluation
3. Feature-to-Benefit Thinking
4. Excel vs ERP Decision
5. Manual Data Entry Problem Analysis

### ReAct
1. Weak Statement Improvement
2. Resume Enhancement
3. CTA Optimization
4. Email Content Fix
5. Bug Description Rewrite

### Self-Consistency
1. ERP Description Refinement
2. ERP FAQ Quality Review
3. Email Subject Line Selection
4. Cloud Computing Simplification
5. ERP Benefits for Managers

## Outcome
Learners gain practical experience in reasoning, evaluation, and content refinement using AI prompting techniques.
