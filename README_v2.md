## 🧩 Technique cheat sheet

| Technique | Best for | Signal in the prompt |
|---|---|---|
| **Zero-Shot** | Familiar, simple tasks | Instruction only, no example |
| **One-Shot** | Matching one specific tone/format | Exactly one worked example |
| **Few-Shot** | Consistency across many outputs | Several examples of the same pattern |

2. **One-Shot** — one Q&A example precedes the real question.
3. **Few-Shot** — repeatable style needs more than one sample to isolate the pattern.

9. Recap:

## 💡 Takeaway

The choice of technique tracks how much of a pattern the model needs to infer: nothing to
learn → zero-shot, one reference point → one-shot, a recurring pattern across many
generations → few-shot. Regardless of technique, specificity (Exercise 7) is what actually
cuts down on ambiguity.
