## 🧠 Summary of concepts

| Technique | When to use | Example cue |
|---|---|---|
| **Zero-Shot** | Simple, well-known task, no examples needed | "Summarize this in one sentence." |
| **One-Shot** | Need to match a specific tone/format from one reference | One Q&A pair, then a new question |
| **Few-Shot** | Need consistent style/pattern across many outputs | Several examples showing the same pattern |

## 📝 Key takeaway

Prompt technique choice comes down to **how much pattern the model needs to infer**:
none → zero-shot, a single reference → one-shot, a repeatable pattern across many
outputs → few-shot. Specificity (as in Exercise 7) matters regardless of technique —
clearer constraints always produce more reliable output.
